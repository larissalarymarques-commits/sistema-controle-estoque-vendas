# Funcionalidades do Sistema

O sistema de controle de estoque e vendas terá as seguintes funcionalidades:

- Cadastro de produtos com nome, preço e quantidade.
- Consulta dos produtos cadastrados.
- Registro de entrada de mercadorias.
- Registro de vendas.
- Atualização automática do estoque após cada venda.
- Identificação de produtos com estoque baixo.

O objetivo é facilitar a organização e o gerenciamento de uma loja de roupas.
