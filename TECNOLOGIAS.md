# Tecnologias Previstas

O desenvolvimento do sistema poderá utilizar as seguintes tecnologias:

- HTML: estrutura das páginas.
- CSS: estilização e organização visual.
- JavaScript: funcionalidades e interatividade.
- Git: controle de versão.
- GitHub: armazenamento e acompanhamento do projeto.

As tecnologias serão aplicadas durante as etapas de desenvolvimento do sistema.
