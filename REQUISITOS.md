# Requisitos do Sistema

## Requisitos funcionais

- RF01: O sistema deve permitir cadastrar produtos.
- RF02: O sistema deve permitir consultar produtos.
- RF03: O sistema deve registrar entradas de mercadorias.
- RF04: O sistema deve registrar vendas.
- RF05: O sistema deve atualizar o estoque após cada venda.
- RF06: O sistema deve identificar produtos com estoque baixo.

## Requisitos não funcionais

- RNF01: O sistema deve apresentar interface simples e intuitiva.
- RNF02: O sistema deve organizar as informações de forma clara.
- RNF03: O sistema deve funcionar em computadores e celulares.

## Objetivo

Facilitar o controle de estoque e vendas de uma loja de roupas.
