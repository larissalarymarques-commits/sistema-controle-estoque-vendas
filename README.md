# Sistema de Controle de Estoque e Vendas

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema web para auxiliar na gestão de uma loja de roupas, facilitando o controle de produtos, estoque e vendas.

A proposta busca melhorar a organização das informações comerciais, reduzir erros nos registros e tornar o acompanhamento do estoque mais eficiente.

## Objetivo

Desenvolver um MVP (Produto Mínimo Viável) para organizar produtos, acompanhar quantidades disponíveis e registrar vendas.

## Funcionalidades previstas

- Cadastro de produtos.
- Consulta de produtos cadastrados.
- Controle de entrada e saída de estoque.
- Registro de vendas.
- Atualização das quantidades em estoque.
- Identificação de produtos com estoque baixo.
